Hourly Energy Consumption Forecasting – Structured ML Pipeline

A modular time series forecasting system built with Prefect, XGBoost, MLflow, FastAPI, Docker and Make.

This project focuses on building a reproducible ML workflow with clear data separation and experiment tracking.

Project Scope

This repository implements:

Orchestrated training pipeline (Prefect)

Time-series feature engineering

XGBoost regression model

Experiment tracking with MLflow

Model serving via FastAPI

Docker-based containerization

Unit testing with Pytest

Makefile-driven execution

Structured data directory (data/, processed

Problem Definition

Forecast hourly electricity consumption using historical time series data.

The system is designed as a structured ML workflow with:

Reproducibility

Modularity

Experiment traceability

Clear raw vs processed data separation

Project Structure
├── data/              # Raw dataset (user places dataset here)
├── processed/         # Feature-engineered data (generated by pipeline)
├── src/
│   ├── training/
│   ├── features/
│   ├── api/
│   └── utils/
├── tests/
├── Makefile
├── Dockerfile
└── requirements.txt

processed/ folder is intentionally empty and is automatically populated during the training pipeline.

Data Setup

Create a data/ directory in the root.

Place the dataset inside:

data/hourly_energy.csv

Ensure an empty processed/ directory exists:

processed/
Run with Make
Install dependencies
make install
Run training pipeline
make train

This will:

Load data from data/

Generate time-series features

Save engineered dataset into processed/

Train XGBoost model

Log experiment to MLflow

Register best model

Design Philosophy

This project emphasizes:

Clean ML system structure

Reproducible experimentation
